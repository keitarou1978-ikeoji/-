# Phase 2 セットアップ手順（CSV取込・取引台帳）

Phase 2 は既存ブックへの**完全追加型**です。既存の入力データや Phase 1 の
VBA（modConfig/modManualEntry/modUtils/shtManual）は**変更不要**。新しい
モジュールを3本入れて、セットアップマクロを1回実行するだけで完成します。

## ① 新モジュールを3本インポート（Shift-JIS版）

VBE（開発タブ → Visual Basic）→ プロジェクトで対象ブックを選択 →
`ファイル → ファイルのインポート` で、`vba_sjis/` の以下3ファイルを取り込みます。

- `modLedger.bas` … 取引台帳への追記・採番・重複排除・手入力転記の本接続
- `modImport.bas` … CSV読込・解析・自動分類・プレビュー→台帳取込
- `modSetup.bas` … Phase 2 セットアップ（シート・ボタン・マッピング生成）

> Phase 1 の6ファイルはそのままでOK。差し替え不要です。

## ② セットアップを1回だけ実行

`Ctrl+G`（イミディエイト ウィンドウ）で次を実行:

```
modSetup.Setup_Phase2
```

これで次が自動生成されます。

- **取引台帳シート**（濃紺タブ）… 全取引の正本
- **CSV取込シート**（緑タブ）… 取込プレビュー＋ボタン4種
  - 「口座CSVを取込」「カードCSVを取込」「取引台帳へ取込」「プレビュー消去」
- **手入力シートの「取引台帳へ転記」ボタン**を本接続
- **設定シート**の CSV列マッピング／自動分類ルールを初期化

「Phase 2 のセットアップが完了しました。」と出れば成功です。

## ③ 手入力→台帳の転記を確認

1. 手入力シートで（Phase 1 のサンプルが残っていればそのまま）
2. 上部の「**取引台帳へ転記**」ボタンを押す
3. 取引台帳シートに明細が追加され、手入力シートH列に「済」が付きます
   （もう一度押しても、重複はスキップされます）

## ④ CSV取込を確認（サンプル付き）

同梱のサンプル（Shift-JIS）で試せます。

- `samples/口座サンプル.csv`
- `samples/カードサンプル.csv`

手順:
1. CSV取込シートで「**口座CSVを取込**」→ `口座サンプル.csv` を選択
2. プレビューに明細が並ぶ（**黄色＝未分類**。例「謎の引落ABCサービス」）
3. 未分類行は F列（大分類）ドロップダウン等で修正（任意）
4. 「**取引台帳へ取込**」→ 台帳へ追記（重複は自動スキップ）
5. 同様に「カードCSVを取込」→ `カードサンプル.csv` でカード明細も取込

## CSV列マッピング（設定シート I〜L 列）

実際の口座/カードCSVに合わせて**列番号などを編集**してください。

| 種別 | 項目 | 初期値 | 意味 |
|------|------|--------|------|
| 口座 | 見出し行数 | 1 | 先頭の見出し行数 |
| 口座 | 日付列 / 摘要列 / 出金列 / 入金列 | 1 / 2 / 4 / 5 | 1始まりの列番号 |
| 口座 | 文字コード | Shift_JIS | UTF-8 の場合は書き換え |
| 口座 | 既定支払方法 | メガバンク口座引落 | 台帳に記録する支払方法 |
| カード | 日付列 / 摘要列 / 金額列 | 1 / 2 / 5 | 1始まりの列番号 |
| カード | 既定支払方法 | クレジットカード | |

- 口座は「出金列に値→支出／入金列に値→収入」で判定します。
- カードは全件「支出」扱いです。
- 日付は `YYYY/MM/DD` `YYYY-MM-DD` `YYYYMMDD` などを自動解釈します。

## 自動分類ルール（設定シート O〜Q 列）

摘要に**キーワードが含まれれば**その大分類/中分類を自動設定します（部分一致）。
初期20件を投入済み。店名などを追記すれば取込精度が上がります。

## 重複排除の仕組み

`日付＋金額＋摘要先頭20字＋支払方法` をキーに、台帳K列で重複判定します。
同じCSVを二度取り込んでも、既存分はスキップされます。

## トラブル時

- 「取引台帳シートがありません」→ ②の `Setup_Phase2` を先に実行。
- 文字化け → `vba_sjis/` 版を使っているか確認（UTF-8版は文字化けします）。
- CSVの金額/日付がずれる → 設定シートの列番号・文字コードを実CSVに合わせて修正。
