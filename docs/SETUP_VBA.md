# VBA セットアップ手順（Phase 1）

`人生奪還PJ_資金管理ツール_v1.xlsm` はシート構造・マスタ・入力規則・名前付き範囲までを
ビルド済みです。VBA 本体（`vba/` 配下）は Excel 上で取り込んで有効化します。
（プログラムからマクロバイナリを埋め込めないため、この手順が必要です。）

## 1. ブックを開く

`人生奪還PJ_資金管理ツール_v1.xlsm` を Excel で開きます。マクロ有効ブックとして
認識されます（セキュリティバーが出たら「コンテンツの有効化」）。

## 2. VBE を開く

`Alt + F11` で Visual Basic Editor を起動します。

## 3. 標準モジュールをインポート

VBE メニュー `ファイル > ファイルのインポート` から、以下を順に取り込みます。

- `vba/modConfig.bas`
- `vba/modManualEntry.bas`
- `vba/modUtils.bas`

## 4. 手入力シートのイベントコードを貼り付け

`shtManual.cls` は**シートモジュール**用のコードです。インポートではなく貼り付けます。

1. プロジェクトエクスプローラで **手入力シート**（`Microsoft Excel Objects` 配下）を
   ダブルクリック。
2. `vba/shtManual.cls` の `Option Explicit` 以降（ヘッダー属性行を除く本体）を
   コピーして、そのシートモジュールに貼り付けます。

## 5. CodeName を確認

各シートを選択し、プロパティウィンドウ（`F4`）の `(オブジェクト名)` を確認します。

- 設定シート → `shtConfig`
- 手入力シート → `shtManual`

ビルド時に設定済みですが、異なる場合はここで合わせてください（VBA はこの CodeName で
シートを参照します）。

## 6. 入力規則の初期化（任意）

B列・F列のドロップダウンはビルド済みですが、再設定したい場合は
イミディエイトウィンドウ（`Ctrl + G`）で次を実行します。

```
modManualEntry.SetupManualValidation
```

## 7. 「取引台帳へ転記」ボタンの配置

1. 手入力シートで `開発 > 挿入 > フォームコントロール > ボタン` を選び、
   上部の赤いラベル「▶ 取引台帳へ転記」（A2:C2）付近に配置。
2. マクロの登録ダイアログで `modManualEntry.TransferToLedger` を選択。

Phase 1 では枠のみのため、押すと「Phase 2 で有効になります」の案内が表示されます。

## 8. 動作確認（テストデータ生成）

イミディエイトウィンドウで次を実行すると、手入力シートに今月分のサンプル10件が入ります。

```
modUtils.Test_GenerateSampleData
```

- B列で大分類を選ぶと C列（中分類）の候補が連動して切り替わることを確認。
- B〜F列に入力すると A列へ今日の日付が自動セットされることを確認。
- 大分類に応じて G列（収支区分）が自動判定されることを確認。

## 再ビルドについて

シート構造やマスタを変更する場合は `python build/build_workbook.py` で
`.xlsm` を作り直せます（VBA は再度 3〜4 の手順で取り込み）。
`build/verify_sampledata.py` はテストデータ生成ロジックの検証用です。
